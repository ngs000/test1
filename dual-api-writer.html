Geração

O piso força continuações mesmo quando o modelo decide parar sozinho (finish_reason "stop") antes de atingir esse número de palavras — é a causa mais comum de respostas curtas apesar de max_tokens alto. Ex.: 5000 para bater o mínimo do teu sistema de escrita.

"Automático" não envia o campo de thinking/reasoning — o provider usa o próprio default. Cada continuação reenvia o histórico + o texto parcial e pede para retomar exatamente onde parou.

Já vem preenchido para usar com o server.py/start.bat incluídos. Se a API der "Failed to fetch" / erro de CORS, confirma que o server.py está a correr. Com o campo vazio, a ferramenta chama a API diretamente.
